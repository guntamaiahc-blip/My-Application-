Movie Booking JavaScript Demo

Files:
- index.html: Complete booking application.

How to run:
1. Extract the ZIP file.
2. Open index.html in a web browser.
3. Click "Book Ticket".
4. Enter your name.
5. Click "Confirm Booking".
6. After successful booking, the booking window is hidden.

Note:
This is a front-end demo. It does not store bookings in a database or process real payments.
